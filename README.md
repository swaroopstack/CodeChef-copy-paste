# CodeChef Clipboard Unlocker

Restores copy, paste, cut and select-all inside CodeChef's code editor.

## Install

1. Download the latest `codechef-clipboard-1.1.8.zip` from [Releases](https://github.com/swaroopstack/CodeChef-copy-paste/releases/latest).
2. Unzip it.
3. Open `brave://extensions`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the unzipped `codechef-clipboard-1.1.8` folder.
7. Open CodeChef and click the editor once.

## Use

- `Ctrl+C` copies the selection, or the whole file if nothing is selected.
- `Ctrl+V` pastes.
- `Ctrl+X` cuts.
- `Ctrl+A` selects all.

A small **Copy / Paste** bar also appears on the page.
